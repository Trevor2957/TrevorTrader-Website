TREVORTRADER DAILY REVIEW STANDARD

For each trading day:

1. Pull completed trades from Cloud Memory.
2. Reconcile every completed trade to Alpaca.
3. Resolve missing or duplicate records.
4. Populate ONLY verified values.
5. Generate the dated responsive Daily Review.
6. Preserve the full Life of Every Trade evidence:
   - Desktop: complete trade table.
   - Mobile: responsive trade cards.
7. Bottom section stays focused on:
   - Daily Learning
   - Adjustments to Test
8. Archive each verified review permanently at:
   /daily-review/YYYY-MM-DD/
9. Maintain /daily-review/index.html as the permanent
   Daily Review Archive. NEVER replace it with a dated review.
10. Maintain /daily-review/latest/ as the pointer to the
    newest verified Daily Review.
11. Daily Review navigation should provide access to:
    - TrevorTrader Home
    - All Reviews
    - Latest Review
12. Publish ONLY after reconciliation is verified.

Learning loop:

MEMORY -> LEARN -> PROPOSE -> BACKTEST -> VALIDATE -> MODIFY

Never invent starting/ending equity, triggers, regime, MFE/MAE,
Daily Learning, strategy adjustments, or any other field that was
not captured and verified.

Never allow a Daily Review publication to modify trading strategy
logic, execution logic, Cloud Memory evidence, or reconciliation data.

Paper validation remains the required environment until a strategy
has completed the required validation process and is explicitly
approved for live capital.
